# Advanced Features

This section covers features added in recent plugin versions (v13.12 through v13.15) that go beyond the basic purchase flow:

- [Storefront API](../storefront-api.md) — retrieve the user's billing country for regional pricing or compliance
- [Multi-Quantity Consumables](../multi-quantity.md) — order multiple units in a single transaction (iOS + Android)
- [Validator Privacy Policy](../privacy-policy.md) — control what data is sent with validation requests
- [Google Play Billing 8.3](../google-play-billing.md) — one-time product offers, suspended subscriptions, pending purchases
